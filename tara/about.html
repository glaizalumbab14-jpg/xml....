About Rentarium

A complete apartment rental management system designed for efficiency and convenience.

Our Mission

Rentarium aims to simplify apartment rental management by providing a centralized platform for landlords and tenants. We eliminate the hassles of manual record-keeping and provide real-time access to important information.

System Overview

Admin Features

  • Create and manage tenant accounts
  • Track room availability and occupancy
  • Process rental requests
  • Record and verify payments
  • Post announcements
  • Generate reports

Tenant Features

  • Browse available rooms
  • Submit rental requests
  • Make payments (simulated)
  • View payment history
  • Read announcements
  • Track rental status

Security Features

For improved security, only administrators can create tenant accounts. This prevents unauthorized registration and ensures proper verification of all tenants.

Admin-Only Registration

Tenants cannot self-register

Role-Based Access

Separate admin and tenant portals

Local Data Storage
